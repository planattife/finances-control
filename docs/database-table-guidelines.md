# PostgreSQL Database Standards & Conventions (GMT 0 / UTC)

Always follow these rules when generating or editing SQL scripts

### 1. Table Creation Safety
- **Always** use `CREATE TABLE IF NOT EXISTS` to ensure scripts are idempotent.

### 2. Naming Conventions
- **Tables:** Use **PascalCase** and pluralized names (e.g., `Users`, `Transactions`).
- **Columns:** Use **PascalCase** to maintain direct mapping with .NET 9 properties.
- **Quotes:** In order to PostgreSQL keep the PascalCase surround table and colum names with quotes.
- **Primary Keys:** The column must be named `Id` using the **BIGINT** type with `GENERATED BY DEFAULT AS IDENTITY`.

### 3. Mandatory Audit Columns (Strictly UTC / GMT 0)
Every table must include these specific columns. We do **not** use Time Zones in the database; all conversion is handled by the Front-end.
- `CreatedAt`: `TIMESTAMP` NOT NULL DEFAULT (now() AT TIME ZONE 'utc').
  - *Mapping:* `public DateTime CreatedAt { get; private set; }`
- `UpdatedAt`: `TIMESTAMP` NULL.
  - *Mapping:* `public DateTime? UpdatedAt { get; private set; }`

### 4. Data Types & Constraints
- **Strings:** Use `TEXT` or `VARCHAR(n)`.
- **Foreign Keys:** Use the pattern `TargetTableNameId` (e.g., `UserId`).
- **Numbers:** Use `DECIMAL(18,2)` for currency/prices.

### 5. Clean script
- Create the script without comments and without empty lines.

### 6. Script file
- **Naming:** vCurrentVersion_create_tablename-table.sql
- **Version:** In the current version save the file name with "-" rather than "." in the current. Example: v1-0-0_create_orders_table.sql
- **Save:** Scripts need to be saved in a folder with the same name as the version inside FinancesControle.API/Database/Tables. Example: Database/Tables/1.0.0/v1-0-0_create_orders_table.sql

### Reference SQL Example:
```sql
CREATE TABLE IF NOT EXISTS "Orders" (
    "Id" BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "OrderNumber" TEXT NOT NULL,
    "TotalAmount" DECIMAL(18,2) NOT NULL,
    "CustomerId" BIGINT NOT NULL,
    "CreatedAt" TIMESTAMP NOT NULL DEFAULT (now() AT TIME ZONE 'utc'),
    "UpdatedAt" TIMESTAMP NULL,
    CONSTRAINT "FK_Orders_Customers_CustomerId" 
        FOREIGN KEY ("CustomerId") REFERENCES "Customers"("Id") 
        ON DELETE RESTRICT
);
